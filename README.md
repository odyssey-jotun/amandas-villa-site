# Amanda's Villa Landscaping and Garden Center: website

Static site for Amanda's Villa (White Hall, Arkansas), built by Outset Web Design. One folder per URL; every link and image path is relative, so the site works on GitHub Pages and on a custom domain.

## Pages

| URL | Status |
|---|---|
| `/hardscape/` | Built: StoryBrand landing page, 3D coverflow gallery of Colton's jobs, before-and-after pairs |
| `/garden-center/` | Built: umbrella page for everything sold on the lot |
| `/` (home), `/landscaping/`, `/about/`, `/contact/` | Under construction |
| `/garden-center/plants-shrubs-trees/`, `houseplants/`, `mulch-soil/`, `landscaping-stone/`, `pottery-decor/`, `produce/` | Under construction |

Under-construction pages show an animated cross-section of a walkway being built (dig, gravel base, fine base, pavers, sprout). They are generated by `python3 tools/build-under-construction.py`; remove a path from that script's `PAGES` list once its real page exists, or the script will overwrite it.

Every page carries `noindex` until the site launches.

## Preview locally

```
python3 -m http.server 8765
```

Then open http://localhost:8765/hardscape/.

## Notes

- Design system: linen, forest green, stone and one clay accent; Libre Caslon Display and Text with Source Sans 3. Rounded photo corners. No eyebrow labels, no external links.
- Photos: `img/` (garden center) and `img/hardscape/` (Colton's jobs). Stock hero credit in `img/hardscape/CREDITS.md`.
- Copy drafts, Colton's interview and the proposal live in the private `odyssey-jotun/amandas-villa` repo.
