# Amanda's Villa Landscaping and Garden Center: website

Static site for Amanda's Villa (White Hall, Arkansas), built by Outset Web Design. One folder per URL; every link and image path is relative, so the site works on GitHub Pages and on a custom domain.

## Pages

| URL | Status |
|---|---|
| `/hardscape/` | Built: StoryBrand landing page, 3D coverflow gallery of Colton's jobs, before-and-after pairs |
| `/landscaping/` | Built: StoryBrand landing page, gallery and before-and-after pairs from Amanda's Facebook jobs; Amanda photo placeholder |
| `/garden-center/` | Built: umbrella page for everything sold on the lot |
| `/about/` | Built: Amanda, Colton, three centered service icons; both photos are placeholders, hero is stock |
| `/` (home) | Built: tagline hero (family planting, stock stand-in), value, problem, services, Amanda + Colton guide, reviews, plan, before-and-after, FAQ |
| `/contact/` | Built: phone, address and directions anchor (`#directions`), what to have ready, FAQ; stock hero |
| `/garden-center/plants-shrubs-trees/`, `landscaping-stone/`, `pottery-decor/`, `produce/` | Built: StoryBrand category pages with Marc's lot photos; stock heroes |
| `/garden-center/houseplants/`, `hanging-baskets/`, `mulch/`, `soil/`, `compost/` | Under construction: waiting on Amanda (bulk pile names, super soil supplier, houseplant and basket stock) |

Under-construction pages show an animated cross-section of a walkway being built (dig, gravel base, fine base, pavers, sprout). They are generated by `python3 tools/build-under-construction.py`; Contact and the four built category pages are generated by `python3 tools/build-pages.py`, which reuses the Garden Center page's styles; remove a path from that script's `PAGES` list once its real page exists, or the script will overwrite it.

Every page carries `noindex` until the site launches.

## Menu and footer

Every built page shares one menu (with the Garden Center dropdown) and one footer, written by `python3 tools/site_nav.py`. To add a finished page to the dropdown, add it to `GARDEN_CENTER` in that script and run it. Under-construction pages stay out of the menu.

## Preview locally

```
python3 -m http.server 8765
```

Then open http://localhost:8765/hardscape/.

## Notes

- Design system: linen, forest green, stone and one clay accent; Libre Caslon Display and Text with Source Sans 3. Rounded photo corners. No eyebrow labels, no external links.
- Photos: `img/` (garden center), `img/hardscape/` (Colton's jobs) and `img/landscaping/` (landscaping jobs from the Facebook page). Stock hero credits in each folder's `CREDITS.md`.
- Copy drafts, Colton's interview and the proposal live in the private `odyssey-jotun/amandas-villa` repo.
